# Taj YouTube — Telegram-бот: скачивание видео, MP3 и фото

Принимает ссылку на YouTube, Instagram или TikTok и присылает видео (360p–1080p),
MP3 или фото. Языки: таджикский и русский.

## Возможности

- Видео / MP3 / фото, проценты загрузки и отправки
- Видео больше 50 МБ автоматически сжимается
- Вопрос «скачать без звука?», если у видео нет аудио
- Обязательная подписка на каналы (список меняет админ командой `/channels`)
- Приглашение друзей `/invite`: за 3 друзей подписка не нужна
- Авто-режим `/auto`: бот запоминает последний формат и качает без вопросов
- Очередь загрузок и защита от спама
- Для админа: `/stats`, `/broadcast`, `/channels`, `/update`, `/id`

## Файлы

`bot.py`, `Dockerfile`, `requirements.txt`, `railway.json`, `README.md`

**Токен и cookies в репозиторий не класть** — только в переменные Railway.

## Деплой на Railway

1. Залей проект на GitHub (приватный репозиторий).
2. Railway → New Project → Deploy from GitHub repo.
3. Variables → добавь переменные (таблица ниже).
4. Settings → Volumes → Add Volume, путь `/data` (там хранится база пользователей).
5. Запускай **только одну реплику**, иначе будет конфликт getUpdates.
6. Сделай бота **администратором** каналов, на которые нужна подписка.

## Переменные

| Переменная | Нужна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `ADMIN_ID` | да | твой Telegram ID (узнать: команда `/id`), можно несколько через запятую |
| `COOKIES_B64` | для YouTube/Instagram | cookies в Base64 (см. ниже) |
| `DB_PATH` | нет | путь к базе; по умолчанию `/data/bot.db`, если есть том `/data` |
| `PROXY_URL` | нет | прокси, например `http://логин:пароль@хост:порт` |
| `PROXY_FOR` | нет | `instagram` (по умолчанию) или `all` |
| `MAX_PARALLEL` | нет | сколько загрузок одновременно (по умолчанию 2) |
| `RATE_LIMIT` | нет | загрузок в минуту на человека (по умолчанию 3) |
| `AUTO_UPDATE_YTDLP` | нет | `0` — не обновлять yt-dlp при запуске |

## Cookies (Instagram и YouTube)

1. Экспортируй cookies в формате Netscape (расширение «Get cookies.txt LOCALLY»).
   Для YouTube: окно инкогнито → вход → `youtube.com/robots.txt` → Export.
2. Объедини cookies обоих сайтов в один текстовый файл (одна строка заголовка
   `# Netscape HTTP Cookie File` сверху).
3. Закодируй: `base64 -w0 cookies.txt` (macOS: `base64 -i cookies.txt`).
4. Вставь результат в `COOKIES_B64` на Railway.

Используй отдельные аккаунты для бота, не основные.

## Если перестало качать

- Отправь боту `/update` (обновит yt-dlp и перезапустит бота).
- Обнови cookies.
- Для Instagram с серверных IP может понадобиться прокси (`PROXY_URL`).

## Ограничения

- Telegram Bot API: файлы до 50 МБ (длинные видео сжимаются).
- Качай только то, на что есть права.
